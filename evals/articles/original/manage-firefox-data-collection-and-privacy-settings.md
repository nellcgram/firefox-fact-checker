# Manage Firefox data collection and privacy settings

Windows 10 reached EOS (end of support) on October 14, 2025. If you are on Windows 10, see [**this article**](https://support.mozilla.org/kb/firefox-support-windows-10-end-support).

Firefox handles your data with transparency. To learn more, read the [Firefox](https://www.mozilla.org/privacy/firefox/) [Privacy Notice](https://www.mozilla.org/privacy/firefox/).

Firefox balances privacy with performance by collecting limited data, such as usage trends, crash reports, and system details, to improve stability and functionality.

This article provides an overview of what’s included in your system settings, where you can control data collection and usage on desktop; guidance is also available for [mobile](https://support.mozilla.org/en-US/kb/mobile-manage-firefox-data-collection-and-privacy).

## Manage settings involving data collection on desktop

To manage technical and interaction data, studies, the daily usage ping and the automatic sending of crash reports:

**First, open Firefox settings for data collection and use**

1. In the Menu bar at the top of the screen, click Firefox and select Settings (or Preferences, in some cases).

2. On the left-hand side, click Permissions and data.

3. Scroll down to the **Firefox data collection and use** section.

**Next, choose what to share** Uncheck or check the following options based on your preferences:

- **Send technical and interaction data to Mozilla** – Helps improve Firefox features, performance and stability. For details, see [Manage technical and interaction data](https://support.mozilla.org/en-US/kb/technical-and-interaction-data) [collection settings in Firefox](https://support.mozilla.org/en-US/kb/technical-and-interaction-data). This setting also enables the following two options:

- **Allow personalized extension recommendations** – Provides tailored extension suggestions.

- **Allow Firefox to run feature studies** – Allows Mozilla to test experimental features before public release. For details, see [About Studies](https://support.mozilla.org/en-US/kb/shield).

- **Allow Firefox to improve features, performance, and stability between updates** - Lets Firefox automatically install fixes and feature changes. For details, see [Manage remote improvements settings in Firefox](https://support.mozilla.org/en-US/kb/remote-improvements).

- **Send daily usage ping to Mozilla** – Helps Mozilla estimate the number of active users. For details, see [Manage daily usage ping data collection settings in Firefox](https://support.mozilla.org/en-US/kb/usage-ping-settings).

- **Automatically send crash reports** – Sends crash data to help diagnose and fix browser issues. For details, see [Crash reports in Firefox for Desktop](https://support.mozilla.org/en-US/kb/crash-report).

> **Note:** Changes save automatically. Close the Settings tab when you're done.

## Manage sponsored content data, recent activity and weather

**First, open the New Tab content settings** Click the pencil icon on the bottom right corner of your [New Tab page](https://support.mozilla.org/en-US/kb/about-new-tab-page). A panel will open, showing content you can customize.

**Next, choose your New Tab content** Click the toggle next to a section to switch it on or off to show or hide that section.

- **Weather** – Provides the ability to turn on or off the weather widget. For details, see [Customize items on your Firefox New Tab page - Weather](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_weather).

- **Shortcuts** – Provides the ability to turn on or off shortcuts on the New Tab page. For details, see [Customize items on your Firefox New Tab page - Shortcuts](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_shortcuts).

- **Recommended stories** – Provides the ability to turn on or off recommended stories on the New Tab page. For details, see [Customize items on your Firefox New Tab page](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_recommended-stories) [- Recommended stories](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_recommended-stories).

**Opt in or opt out of sponsored content and recent activity**

1. Click the **Manage more settings** link at the bottom of the panel.

- The Home and startup panel will open, with Firefox Home Content settings you can customize.

2. Check or uncheck items in the **Support Firefox** section:

- **Sponsored shortcuts** – Provides the ability to turn on or off sponsored shortcuts on the New Tab page. For details, see [Sponsors on the home page and](https://support.mozilla.org/en-US/kb/sponsor-privacy#w_sponsored-shortcuts) [New Tab page - Sponsored shortcuts](https://support.mozilla.org/en-US/kb/sponsor-privacy#w_sponsored-shortcuts).

- **Sponsored stories** – Provides the ability to turn on or off sponsored stories on the New Tab page. For details, see [Sponsors on the home page and New Tab](https://support.mozilla.org/en-US/kb/sponsor-privacy#w_sponsored-stories) [page - Sponsored stories](https://support.mozilla.org/en-US/kb/sponsor-privacy#w_sponsored-stories)

3. Check or uncheck items in the **Recent activity** section:

- **Recent activity** – Provides the ability to turn on or off thumbnails displaying recent downloads, sites or bookmarks. For details, see [Customize items on your](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_recent-activity) [Firefox New Tab page - Recent Activity](https://support.mozilla.org/en-US/kb/customize-items-on-firefox-new-tab-page#w_recent-activity).
